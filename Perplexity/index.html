03 · The math

Every token has a probability.

How likely the model thought that exact token was, given all the words before it.

Turn it into surprise.

Surprise is −ln p. Likely tokens cost almost nothing; unlikely ones cost a lot.

Average the surprise.

Over all N tokens. That is the model's cross-entropy, measured in nats.

Exponentiate.

Perplexity is e to that average: the number of equally likely choices the model was effectively juggling.

PPL = exp( −1⁄N Σ ln pi )
