02 · Architecture

Pure algorithm.

Input in, answer out. No UI, no animation, no state. boyerMoore.js

Replay generator.

Turns a run into a deterministic list of steps that can be replayed forward, backward or scrubbed. boyerMooreSteps.js

Source metadata.

Reference implementations and line mappings that keep the visible source aligned with every step. stringSources.js

UI components.

React components only render steps. They never know how the algorithm works.

    05 · Testing

    Three ways to trust code.

    Unit tests check cases, invariants check rules that must always hold, and mutation tests check that the tests themselves can fail. Try each one on a live demo.

    UNIT

    Edge cases

    Overlapping matches, missing matches and empty patterns for Boyer-Moore.

      PROPERTY / INVARIANT

      Rules that always hold

      Every row of Pascal's triangle must sum to a power of two.

        MUTATION

        Kill the mutant

        Break the code on purpose. Good tests turn red.
